# 🎞️ Sprite Sheet Packer & CSS Keyframe Generator

An interactive, client-side tool built with React 19, TypeScript, HTML5 Canvas, and Tailwind CSS. Combine individual image frames into an optimized Sprite Sheet PNG and generate ready-to-use CSS `@keyframes` code instantly.

![Tech Stack](https://img.shields.io/badge/stack-React%20%7C%20TypeScript%20%7C%20Canvas-violet)

## ✨ Features

- 🖼️ **Multi-Frame Assembly:** Drag & drop frame PNGs to stitch into a unified Sprite Sheet grid.
- 🎬 **Real-Time Preview:** Test your sprite animation live with adjustable FPS (1-60) and frame scaling.
- 💻 **CSS Code Exporter:** Automatically generates production-ready CSS `steps()` animation snippets.
- ⚡ **100% Client-Side:** Processing done entirely in browser—fast, private, and zero server uploads.
